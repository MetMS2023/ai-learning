吴恩达 Machine Learning Specialization：我的机器学习入门笔记

这份笔记整理自我两年前学习吴恩达 Machine Learning Specialization 时留下的课程记录。两年后重新翻看，它依然是一套非常适合初学者的机器学习入门课程：从线性回归和 Gradient Descent 开始，循序渐进地讲到分类、神经网络、模型诊断、无监督学习、推荐系统和强化学习。如果想系统补齐机器学习基础，我仍然强烈推荐完整学习这套课程。

完整免费课程：Andrew Ng · Machine Learning Specialization YouTube Playlist →
课程主线：选择一种学习方法 → 定义衡量好坏的目标函数 → 用优化算法调整参数 → 在未参与训练的数据上验证 → 根据错误决定下一步。
01

先看全局地图：机器学习在学什么？

不同算法看起来差异很大，但都围绕同一个问题：系统能否从经验中提取规律，并把规律用于新的输入？区别主要在于经验以什么形式出现。

监督学习

训练数据同时包含输入 x 与目标 y。回归预测连续值，分类预测类别或概率。

无监督学习

只有输入 x，系统自行寻找聚类、异常或更紧凑的表示。

强化学习

Agent 与环境互动，通过奖励学习在不同状态下采取什么动作。

为了理解后面所有算法，最适合先从线性回归入手，因为它完整展示了“模型—误差—优化”这条最基本的学习链路。

02

线性回归与 Gradient Descent：第一个完整学习闭环

线性回归用输入特征预测连续数值。只有一个特征时，模型是 f(x)=wx+b：w 控制斜率，b 控制整体上下平移。多个特征时，x 和 w 都变成向量：

f(x) = w·x + b = w₁x₁ + w₂x₂ + … + wₙxₙ + b

这里的 n 表示输入特征数量，而不是输出数量。例如面积、卧室数和房龄是三个特征，但模型仍只预测一个房价。

Loss、Cost 和 Gradient 分别是什么？

Loss 衡量一个样本预测得有多差；Cost J 汇总整个训练集的 Loss；Gradient 是 Cost 对参数的偏导数，表示参数稍微变化时，Cost 朝哪个方向、以多快速度变化。

J(w,b) = (1 / 2m) Σ (f(xᶦ) − yᶦ)²

Gradient Descent 是什么？

Gradient Descent 是一种反复调整参数、让 Cost 逐步下降的优化算法。导数为正表示参数继续增大会让 Cost 上升，因此要向负方向移动；导数为负则相反。Learning rate α 决定每一步走多远。

w := w − α ∂J/∂w　　b := b − α ∂J/∂b

w 和 b 应使用同一轮计算出的梯度同时更新。α 太小会收敛很慢；太大可能跨过最低点、震荡甚至发散。

互动｜亲手调整 w 和 b

拖动参数，让蓝色直线靠近数据点；Cost J 会实时变化。也可以让 Gradient Descent 自动走一步。

让 Gradient Descent 更容易收敛

多特征输入通常写成 f(x)=w·x+b，用 Vectorization 一次完成矩阵运算。若面积是几千、卧室数只有个位数，Gradient Descent 会在狭长等高线中来回摆动；Z-score normalization 等 Feature Scaling 方法能让不同特征处于可比较范围。训练时还要观察 Learning curve：Cost 应整体下降并逐渐趋平。

统一训练骨架线性回归第一次完整展示了 Forward → Loss → Gradient / Backpropagation → Parameter update。后续模型会改变函数形式和 Loss，但这条骨架仍然成立。
03

Logistic Regression：从连续预测到分类概率

分类问题的目标不是预测任意数值，而是判断类别。例如垃圾邮件检测中，y=1 表示垃圾邮件，y=0 表示正常邮件。Logistic Regression 先计算 z=w·x+b，再通过 Sigmoid 映射到 0～1：

ŷ = g(z) = 1 / (1 + e⁻ᶻ)

互动｜Logit、概率与分类阈值

改变 z 会移动 Sigmoid 上的点；改变 threshold 只改变最终决策，不改变模型输出的概率。

为什么分类不用普通 MSE？

二分类通常使用 Binary Cross-Entropy。它强烈惩罚“非常自信但预测错误”的情况，并与 Sigmoid 组合形成适合概率分类的目标：

Loss = −[y log(ŷ) + (1−y) log(1−ŷ)]

Gradient Descent 的更新形式与线性回归看起来相似，但预测函数与 Loss 已不同，因此得到的梯度含义也不同。

从训练拟合走向泛化

Underfitting 表示模型连训练数据的主要规律都没学到，通常对应 High Bias；Overfitting 表示模型把训练数据中的偶然噪声也记住，通常对应 High Variance。

λ=0 不必然导致过拟合；它只是完全不施加正则化。λ 过大则可能把权重压得太小，导致模型过于简单。除了正则化，更多训练数据、减少不必要特征、数据增强也可能改善泛化，具体选择要依赖诊断。

04

进阶监督学习方法：Neural Network 与 Decision Tree

这里的“方法”是什么含义？Neural Network 和 Decision Tree 既可以称算法家族，也可以称模型家族。这里改用“监督学习方法”，避免把“模型”误解为 Opus、Fable、Sol、Seedance 等已经训练完成的具体产品模型。此处讨论的是用于从数据学习映射关系的结构与训练方法。

Neural Network 的基本组成

一个神经元接收多个输入，计算 z=w·x+b，再通过 Activation Function 得到输出。多个神经元组成 Layer；位于输入和输出之间的层叫 Hidden Layer。

Input layer接收原始特征
Hidden layers学习逐层表示
Output layer输出数值、概率或类别

Forward propagation 从输入逐层算到输出；Loss 衡量预测；Backpropagation 利用 Chain Rule 从后往前计算每一层 W 和 b 的梯度。训练框架会自动求导，但 Batch、Epoch、Activation、Loss 和参数矩阵仍是理解网络的基础。

Decision Tree 的基本组成

Decision Tree 不通过层和权重做连续变换，而是不断提出条件问题。Root node 是起点，Decision node 根据某个特征分支，Leaf node 给出最终类别或预测值。

每个节点要选择“用哪个特征、在哪个阈值切分”。分类树常用 Entropy 衡量混杂程度，并选择 Information Gain 最大的切分；回归树则常选择能最大幅度降低加权方差的切分。

树可以在节点纯净、达到最大深度、样本太少或增益过小时停止。树太深容易过拟合；限制深度、最小叶节点样本数等相当于控制模型复杂度。

Tree Ensembles：为什么很多棵树更稳定？

Random Forest 对训练数据做有放回采样，并让每个节点只从随机特征子集中选择切分，制造彼此不同的树，最后投票或平均。Boosting / XGBoost 则按顺序训练新树，让后面的树重点修正前面仍然犯错的样本。

05

ML Diagnostics：先确认哪里出了问题

Train、Cross-validation 和 Test set

Training set

用于计算 Loss、Gradient 并拟合参数。模型会反复看到这些样本。

Cross-validation set

用于选择模型结构、正则化 λ、阈值等超参数，也称 Validation / Dev set。

Test set

在所有选择完成后评估最终泛化能力，应尽量只在最后使用。

如果根据 Test 结果反复改模型，Test set 也会被间接“训练”，分数就不再代表真正未见数据。Normalization、特征选择等步骤也必须只用 Training set 拟合，再应用到 CV 与 Test，避免 Data Leakage。

Bias 与 Variance

将误差与一个合理 Baseline（例如人类表现或简单规则）比较：Training error 已经很高，通常是 High Bias；Training error 低而 CV error 明显更高，通常是 High Variance。

互动｜复杂度怎样影响训练与验证误差？

增加模型复杂度时，Training error 通常继续下降，CV error 则可能先降后升。

Training errorCV error

从 Accuracy 过渡到 Precision、Recall 和 F1

Train / CV / Test 解决的是“用哪份数据评估”；接下来还要决定“用什么指标评估”。类别平衡时 Accuracy 容易理解，但在欺诈检测等极度不平衡场景中，即使模型永远预测“正常”，Accuracy 也可能很高。

概念含义公式
TP预测为正，实际也为正正确命中的正例
FP预测为正，实际为负误报
FN预测为负，实际为正漏报
Precision预测为正的样本中，有多少真的为正TP/(TP+FP)
Recall所有真实正例中，找回了多少TP/(TP+FN)
F1Precision 与 Recall 的调和平均2PR/(P+R)

分类模型先输出概率，再用 Threshold 决定类别。提高 Threshold 会让模型更谨慎地报正例，通常减少 FP、提高 Precision，但也会漏掉更多正例、降低 Recall。

06

无监督学习：没有标签时寻找结构

K-means Clustering

Clustering 的输入没有正确类别。K-means 需要先指定 K 个群组，并为每个群组维护一个 Centroid。算法反复执行两步：把每个样本分给最近中心，再把中心移动到组内样本的平均位置。

Distortion = (1/m) Σ ||xᶦ − μc⁽ⁱ⁾||²

Distortion 越低，样本整体离所属中心越近，但 K 越大也天然更容易降低 Distortion。因此 K 不能只靠最低 Cost 决定，还要结合业务需要；Elbow method 只是参考，而且拐点可能并不明显。

互动｜看清 K-means 的两个动作

空心圆带 × 是 Centroid。点击“随机放置两个中心”，再交替点击分配和移动；蓝橙颜色表示样本当前归属。

○ 灰色：未分配样本● 蓝/橙：已分配样本⊗ 空心圆：Centroid

Anomaly Detection

异常检测不是先学习每一种异常，而是估计正常数据的概率分布。对每个特征估计均值 μ 和方差 σ²，组合得到 p(x)；若新样本的密度低于阈值 ε，就标记为异常。ε 应在带少量标签的 CV set 上选择。

何时改用监督分类？如果已有大量、稳定且覆盖充分的异常类型标签，监督分类通常更合适；如果异常稀少、形态不断变化，Density Estimation 更自然。
07

推荐系统与 PCA：从互动中学习表示

推荐系统要预测什么？

推荐系统常预测“某位用户会多喜欢某个物品”。输入可以是评分，也可以是点击、收藏、观看或购买等 implicit feedback。困难在于用户只接触过极少部分物品，因此 User–Item Matrix 大部分位置都是空的。

Collaborative Filtering

协同过滤不要求人为写出所有物品特征。它同时学习用户向量 vᵤ 和物品向量 vₘ，让两者的内积接近已知评分：

predicted_score(user,item) = vᵤ · vₘ + bias

它依赖群体互动，因此新用户或新物品几乎没有历史时会遇到 Cold Start。

Content-based Filtering 与 Two-tower 模型

基于内容的推荐使用用户属性与物品属性。两个 Neural Network 分别把用户特征和物品特征编码成同一向量空间，再用相似度评分。它能利用新物品的文本、类别等信息缓解 Cold Start。

面对大规模 Catalog，通常先用轻量方法 Retrieval 数百个候选，再用更丰富特征 Ranking。离线评测可用 Precision@K、Recall@K 等，但线上还要关注点击、转化、多样性和长期满意度。

PCA：为什么和推荐系统放在同一段学习？

两者都涉及向量表示，但目标不同。PCA 不预测评分，而是寻找数据方差最大的正交方向，把高维数据投影到更少维度。第一个 Principal Component 保留最多方差，后续主成分在与前面正交的条件下继续保留剩余变化。

使用 PCA 前通常需要 Feature Scaling，否则数值范围大的特征会主导方向。降维后会损失信息，因此应检查 Explained Variance，而不是默认维度越低越好。

互动｜旋转投影轴，观察保留的方差

调整轴的角度，点会投影到这条线上。投影后的方差越大，这条轴越能保留数据主要变化。

08

Reinforcement Learning：从预测走向连续决策

先认识六个基础元素

State

环境在当前时刻的状态，例如着陆器的位置和速度。

Action

Agent 可采取的动作，例如向左、向右或点火。

Reward

环境对结果给出的即时反馈，不等同于长期目标。

Policy π(a|s)

在状态 s 下选择各动作的规则或概率。

Episode

从初始状态到任务结束的一整段交互轨迹。

Return

从当前时刻开始，未来奖励的折扣总和。

MDP 的 Markov Property 假设：给定当前 State，预测未来不再需要完整历史。目标是找到能让 Expected Return 最大的 Policy。

互动｜γ 如何改变 Return？

假设奖励序列是 [0, 2, 0, 10]。γ 越小越重视眼前；γ 越接近 1，远期奖励影响越大。

State-action Value Function：Q(s,a) 到底表示什么？

State-action Value Function 通常简称 Q-function。它回答一个非常具体的问题：

如果现在处于 State s，立即采取 Action a，之后继续行动，预期一共能获得多少折扣后的未来奖励？

Q(s,a) 的值取决于之后采用的 Policy；Q*(s,a)（Optimal Q-function）表示从这一步开始，之后始终做出最佳选择时能够得到的最高 Expected Return。若已经知道 Q*，最佳 Policy 就很简单：

π*(s) = argmaxₐ Q*(s,a)
当前 State可选 Action假设的 Q 值
着陆器位于平台上方，正在快速下降不操作Q(s, nothing) = 2
向左Q(s, left) = 1
主引擎点火Q(s, main) = 8
向右Q(s, right) = 0

在这个例子中，Agent 会选择“主引擎点火”。Q 不是“这个动作马上得到几分”，而是把这个动作对未来整段轨迹的影响也计算进去。

Bellman Equation：把长期价值拆成一步

复杂任务的最终 Return 可能要很久以后才知道。Bellman Equation 提供一个递归关系：一个动作的价值，等于当前立即得到的 Reward，加上下一 State 能获得的最佳未来价值。

Q*(s,a) = r + γ maxₐ′ Q*(s′,a′)
代入一个数字例子

假设采取动作后立即得到 r=2，进入新状态 s′；在 s′ 中最好的动作价值是 8，折扣因子 γ=0.9。那么当前动作应该逼近的目标是：y = 2 + 0.9×8 = 9.2。

Deep Reinforcement Learning：用 Neural Network 近似 Q*

状态很少时，可以用 Q-table 为每个 (s,a) 保存一个数字。但图像、位置、速度等连续 State 几乎有无限组合，表格无法穷举。DQN（Deep Q-Network）因此使用 Neural Network 作为 Q-function approximator：

输入当前 State s
Neural Network共享隐藏层提取状态表示
输出每个离散 Action 的 Q 值

DQN 是怎样“学会”Q 值的？

Neural Network 一开始输出的 Q 几乎是随机的。环境不会直接提供正确 Q，只提供一次交互结果 (s,a,r,s′)。DQN 使用 Bellman Equation 构造一个暂时的学习目标：

TD target: y = r + γ maxₐ′ Q_target(s′,a′)

主网络对刚才动作的预测是 Q_online(s,a)。两者差距形成 Temporal-Difference error，并像监督学习一样用 Squared Error 训练：

Loss = [Q_online(s,a) − y]²

调整即时奖励、γ、下一状态最佳 Q 和主网络当前预测。点击训练一步，观察预测值向 TD target 靠近。

为什么还需要三个稳定机制？

Experience Replay

连续 transition 高度相关。随机抽样打散顺序，并让同一经验可被多次利用。

Target Network

如果预测值和训练目标都由同一个快速变化的网络产生，目标会不断移动，训练容易震荡。

ε-greedy

只选当前最大 Q 会错过更好动作；保留 ε 概率随机探索，在 Exploration 与 Exploitation 间平衡。

RL 的适用边界奖励设计错误会产生 Reward Hacking；交互数据昂贵，训练也可能不稳定。RL 适合动作、反馈和环境可定义的问题，不是所有智能任务的默认方案。
走完整条学习路径回归与分类学习输入到目标的映射；神经网络和树扩展函数能力；Diagnostics 决定如何迭代；无监督学习寻找结构；推荐系统学习偏好表示；RL 最终把“预测什么”扩展为“接下来做什么”。
