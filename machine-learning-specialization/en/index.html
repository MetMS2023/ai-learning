Andrew Ng’s Machine Learning Specialization: My Machine Learning Foundations Notes

These notes are compiled from my course records left behind when I studied Andrew Ng's Machine Learning Specialization two years ago. Looking back after two years, it remains an excellent introductory machine learning course for beginners: starting with linear regression and Gradient Descent, it progresses step-by-step to classification, neural networks, model diagnostics, unsupervised learning, recommendation systems, and reinforcement learning. If you want to systematically fill in your machine learning foundations, I still strongly recommend completing this entire course.

01

The Big Picture: What Does Machine Learning Learn?

Different algorithms may look very different, but they all revolve around the same question: can a system extract patterns from experience and apply those patterns to new inputs? The main difference lies in the form the experience takes.

Supervised Learning

Training data contains both inputs x and targets y. Regression predicts continuous values, while classification predicts categories or probabilities.

Unsupervised Learning

Only inputs x are provided; the system finds clusters, anomalies, or more compact representations on its own.

Reinforcement Learning

An agent interacts with an environment, learning through rewards which actions to take in different states.

To understand all the algorithms that follow, it is best to start with linear regression, as it fully demonstrates the most fundamental learning chain: “model—error—optimization.”

02

Linear Regression and Gradient Descent: The First Complete Learning Loop

Linear regression predicts continuous values from input features. With a single feature, the model is f(x)=wx+b: w controls the slope, and b controls the vertical shift. With multiple features, both x and w become vectors:

f(x) = w·x + b = w₁x₁ + w₂x₂ + … + wₙxₙ + b

Here, n represents the number of input features, not the number of outputs. For example, area, number of bedrooms, and house age are three features, but the model still predicts only one house price.

What are Loss, Cost, and Gradient?

Loss measures how poorly a single sample is predicted; Cost J aggregates the Loss over the entire training set; Gradient is the partial derivative of Cost with respect to the parameters, indicating the direction and rate at which Cost changes when parameters are slightly adjusted.

J(w,b) = (1 / 2m) Σ (f(xᶦ) − yᶦ)²

What is Gradient Descent?

Gradient Descent is an optimization algorithm that iteratively adjusts parameters to gradually reduce Cost. A positive derivative indicates that increasing the parameter further will increase Cost, so the update should move in the negative direction; a negative derivative implies the opposite. The Learning rate α determines the step size for each update.

w := w − α ∂J/∂w　　b := b − α ∂J/∂b

w and b should be updated simultaneously using the gradients calculated in the same iteration. If α is too small, convergence will be very slow; if it is too large, the algorithm may overshoot the minimum, oscillate, or even diverge.

Making Gradient Descent Converge More Easily

Multi-feature inputs are typically written as f(x)=w·x+b, using Vectorization to perform matrix operations in one go. If area is in the thousands while the number of bedrooms is single-digit, Gradient Descent will oscillate back and forth within narrow, elongated contours; Feature Scaling methods like Z-score normalization bring different features into comparable ranges. During training, also monitor the Learning curve: Cost should generally decrease and gradually flatten out.

Unified Training SkeletonLinear regression fully demonstrates the Forward → Loss → Gradient / Backpropagation → Parameter update cycle for the first time. Subsequent models will change the function form and Loss, but this skeleton remains valid.
03

Logistic Regression: From Continuous Prediction to Classification Probability

The goal of a classification problem is not to predict an arbitrary numerical value, but to determine a class. For example, in spam detection, y=1 indicates spam, and y=0 indicates a normal email. Logistic Regression first calculates z=w·x+b, then maps it to the range 0 to 1 using the Sigmoid function:

ŷ = g(z) = 1 / (1 + e⁻ᶻ)

Interactive | Logit, Probability, and Classification Threshold

Changing z moves the point on the Sigmoid curve; changing the threshold only alters the final decision, not the probability output by the model.

Why Not Use Standard MSE for Classification?

Binary classification typically uses Binary Cross-Entropy. It heavily penalizes cases where the model is "very confident but wrong," and combined with the Sigmoid function, it forms an objective suitable for probabilistic classification:

Loss = −[y log(ŷ) + (1−y) log(1−ŷ)]

The update form of Gradient Descent looks similar to that of linear regression, but since the prediction function and Loss are different, the resulting gradients have different meanings.

From Training Fit to Generalization

Underfitting means the model has not even learned the main patterns in the training data, typically corresponding to High Bias; Overfitting means the model has memorized accidental noise in the training data, typically corresponding to High Variance.

λ=0 does not necessarily lead to overfitting; it simply means no regularization is applied at all. If λ is too large, it may suppress weights too much, making the model overly simple. Besides regularization, using more training data, reducing unnecessary features, and data augmentation can also improve generalization; the specific choice depends on diagnosis.

04

Advanced Supervised Learning Methods: Neural Network and Decision Tree

What does "methods" mean here?Neural Network and Decision Tree can be referred to as either algorithm families or model families. Here, we use the term "supervised learning methods" to avoid misinterpreting "model" as specific, pre-trained product models like Opus, Fable, Sol, or Seedance. This section discusses the structures and training methods used to learn mapping relationships from data.

Basic Components of a Neural Network

A neuron receives multiple inputs, computes z=w·x+b, and then produces an output via an Activation Function. Multiple neurons form a Layer; layers located between the input and output are called Hidden Layers.

Input layerReceives raw features
Hidden layersLearn hierarchical representations
Output layerOutputs values, probabilities, or classes

Forward propagation computes from input to output layer by layer; Loss measures the prediction; Backpropagation uses the Chain Rule to calculate the gradients of W and b for each layer from back to front. Training frameworks handle automatic differentiation, but Batch, Epoch, Activation, Loss, and parameter matrices remain the foundation for understanding networks.

Basic Components of a Decision Tree

A Decision Tree does not perform continuous transformations through layers and weights; instead, it continuously poses conditional questions. The Root node is the starting point, a Decision node branches based on a specific feature, and a Leaf node provides the final class or predicted value.

Each node must select "which feature to use and at which threshold to split." Classification trees commonly use Entropy to measure impurity and select the split with the maximum Information Gain; regression trees typically select the split that most significantly reduces weighted variance.

A tree can stop growing when nodes are pure, maximum depth is reached, there are too few samples, or the gain is too small. Trees that are too deep are prone to overfitting; limiting depth, minimum samples per leaf, etc., are equivalent to controlling model complexity.

Tree Ensembles: Why Are Many Trees More Stable?

Random Forest performs sampling with replacement on the training data and allows each node to select splits only from a random subset of features, creating diverse trees that finally vote or average. Boosting / XGBoost trains new trees sequentially, focusing subsequent trees on correcting samples that previous trees still misclassified.

ML Diagnostics: First, Identify Where the Problem Lies

Train, Cross-validation, and Test Sets

Training Set

Used to calculate Loss, Gradient, and fit parameters. The model sees these samples repeatedly.

Cross-validation Set

Used to select model structure, regularization λ, thresholds, and other hyperparameters. Also known as the Validation or Dev set.

Test Set

Used to evaluate final generalization performance after all selections are complete. It should be used only at the very end.

If you repeatedly modify the model based on Test results, the Test set is indirectly "trained" as well, and the score no longer represents truly unseen data. Steps like Normalization and feature selection must also be fitted using only the Training set and then applied to the CV and Test sets to avoid Data Leakage.

Bias and Variance

Compare the error against a reasonable Baseline (such as human performance or simple rules): If the Training error is already high, it is usually High Bias; if the Training error is low but the CV error is significantly higher, it is usually High Variance.

06

Unsupervised Learning: Finding Structure Without Labels

K-means Clustering

Clustering inputs do not have correct classes. K-means requires specifying K groups in advance and maintaining a Centroid for each group. The algorithm repeatedly performs two steps: assigning each sample to the nearest center, and then moving the center to the average position of the samples in that group.

Distortion = (1/m) Σ ||xᶦ − μc⁽ⁱ⁾||²

Lower Distortion means samples are generally closer to their assigned centers, but larger K values naturally make it easier to reduce Distortion. Therefore, K should not be determined solely by the lowest Cost; business needs must also be considered. The Elbow method is only a reference, and the elbow point may not be obvious.

Anomaly Detection

Anomaly detection does not involve learning every type of anomaly first; instead, it estimates the probability distribution of normal data. Estimate the mean μ and variance σ² for each feature, and combine them to get p(x); if the density of a new sample is below the threshold ε, it is marked as an anomaly. ε should be selected on a CV set with a small number of labels.

When to switch to supervised classification?If you already have a large, stable, and sufficiently comprehensive set of labels for anomaly types, supervised classification is usually more appropriate; if anomalies are rare and their forms constantly change, Density Estimation is more natural.
07

Recommendation Systems and PCA: Learning Representations from Interactions

What Do Recommendation Systems Predict?

Recommendation systems often predict "how much a specific user will like a specific item." Inputs can be ratings or implicit feedback such as clicks, favorites, views, or purchases. The difficulty lies in the fact that users have only interacted with a tiny fraction of items, leaving most positions in the User–Item Matrix empty.

Collaborative Filtering

Collaborative Filtering does not require manually defining all item features. It simultaneously learns user vectors vᵤ and item vectors vₘ, ensuring that their dot product approximates known ratings:

predicted_score(user,item) = vᵤ · vₘ + bias

It relies on group interactions, so new users or new items with little history will encounter the Cold Start problem.

Content-based Filtering and Two-tower Models

Content-based filtering uses user attributes and item attributes. Two Neural Networks separately encode user features and item features into the same vector space, then score them based on similarity. It can leverage information such as text and categories for new items to mitigate Cold Start.

When facing a large-scale Catalog, it is common to first use lightweight methods for Retrieval to generate hundreds of candidates, then use richer features for Ranking. Offline evaluation can use metrics like Precision@K and Recall@K, but online systems must also monitor clicks, conversions, diversity, and long-term satisfaction.

PCA: Why Learn It Alongside Recommendation Systems?

Both involve vector representations, but their goals differ. PCA does not predict ratings; instead, it finds the orthogonal directions of maximum data variance and projects high-dimensional data into fewer dimensions. The first Principal Component retains the most variance, while subsequent principal components continue to retain remaining variation under the condition of being orthogonal to previous ones.

Feature Scaling is usually required before using PCA; otherwise, features with large numerical ranges will dominate the directions. Dimensionality reduction results in information loss, so one should check the Explained Variance rather than assuming that lower dimensions are always better.

Reinforcement Learning: From Prediction to Continuous Decision-Making

First, Meet the Six Basic Elements

State

The state of the environment at the current moment, such as the position and velocity of a lander.

Action

An action the Agent can take, such as moving left, moving right, or firing the engine.

Reward

Immediate feedback from the environment regarding the outcome; it is not equivalent to the long-term goal.

Policy π(a|s)

The rule or probability distribution for selecting actions given state s.

Episode

A complete interaction trajectory from the initial state to the end of the task.

Return

The discounted sum of future rewards starting from the current moment.

The Markov Property assumption in an MDP: given the current State, predicting the future does not require the complete history. The goal is to find the Policy that maximizes the Expected Return.

State-action Value Function: What exactly does Q(s,a) represent?

The State-action Value Function is commonly abbreviated as the Q-function. It answers a very specific question:

If we are currently in State s and immediately take Action a, and then continue acting, what is the expected total discounted future reward?

The value of Q(s,a) depends on the Policy adopted thereafter; Q*(s,a) (the Optimal Q-function) represents the highest Expected Return achievable from this step onward if optimal choices are made consistently. If Q* is known, the optimal Policy is straightforward:

π*(s) = argmaxₐ Q*(s,a)
Current StateAvailable ActionsHypothetical Q Values
Lander is above the platform, descending rapidlyDo nothingQ(s, nothing) = 2
Move leftQ(s, left) = 1
Fire main engineQ(s, main) = 8
Move rightQ(s, right) = 0

In this example, the Agent will choose "Fire main engine." Q is not "how many points this action gets immediately," but rather calculates the impact of this action on the entire future trajectory.

Bellman Equation: Breaking Down Long-Term Value into One Step

The final Return for complex tasks may only be known much later. The Bellman Equation provides a recursive relationship: the value of an action equals the immediate Reward received now plus the best future value obtainable from the next State.

Q*(s,a) = r + γ maxₐ′ Q*(s′,a′)
Substituting a numerical example

Assume that after taking an action, an immediate r=2 is received, entering a new state s′; in s′, the best action value is 8, and the discount factor is γ=0.9. Then, the target that the current action should approach is: y = 2 + 0.9×8 = 9.2.

Deep Reinforcement Learning: Approximating Q* with a Neural Network

When there are few states, a Q-table can store a number for each (s,a). However, continuous States such as images, positions, and velocities have nearly infinite combinations, making tables impossible to exhaust. DQN (Deep Q-Network) therefore uses a Neural Network as a Q-function approximator:

InputCurrent State s
Neural NetworkShared hidden layers extract state representations
OutputQ value for each discrete Action

How does DQN "learn" Q values?

Initially, the Q values output by the Neural Network are almost random. The environment does not provide the correct Q directly; it only provides a single interaction result (s,a,r,s′). DQN uses the Bellman Equation to construct a temporary learning target:

TD target: y = r + γ maxₐ′ Q_target(s′,a′)

The main network's prediction for the recent action is Q_online(s,a). The difference between the two forms the Temporal-Difference error, and it is trained using Squared Error, similar to supervised learning:

Loss = [Q_online(s,a) − y]²

Why are three stabilization mechanisms still needed?

Experience Replay

Consecutive transitions are highly correlated. Random sampling shuffles the order and allows the same experience to be used multiple times.

Target Network

If both the prediction and the training target are generated by the same rapidly changing network, the target will keep moving, causing training to oscillate easily.

ε-greedy

Only selecting the current maximum Q will miss better actions; retaining a probability ε for random exploration balances Exploration and Exploitation.

Boundaries of RL ApplicabilityIncorrect reward design leads to Reward Hacking; interaction data is expensive, and training may be unstable. RL is suitable for problems where actions, feedback, and environments can be defined, but it is not the default solution for all intelligent tasks.
Walking the Complete Learning PathRegression and classification learn the mapping from input to target; neural networks and trees expand functional capacity; Diagnostics determine how to iterate; unsupervised learning finds structure; recommendation systems learn preference representations; RL ultimately expands "what to predict" into "what to do next."
